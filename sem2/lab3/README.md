# Pacman (Pygame)

## Описание проекта
Это реализация классической игры Pacman на Python с использованием библиотеки Pygame.  
Игрок управляет персонажем, собирает точки и бонусы, избегает врагов и пуль. В проекте реализованы:

- Движение игрока с плавными поворотами по центру туннелей.
- Враги с разными поведениями: случайное движение и преследование игрока.
- Система бонусов с эффектами: ускорение и телепорт.
- Таблица рекордов (топ-5).
- Окно "Справка" с правилами игры.
- Музыка и звуковые эффекты.
- Экраны Game Over и Победа.

## Управление

- **Стрелки**: движение игрока
- **ESC**: выход из меню или экрана помощи
- **ENTER**: подтверждение выбора в меню или restart после Game Over

---

## Игровые механики

- Игрок должен собрать все точки на карте.
- Бонусы дают специальные эффекты:
  - **Ускорение**: временное увеличение скорости
  - **Телепорт**: случайное перемещение в свободное место
- Враги:
  - **Random Shooter**: двигается случайно и стреляет в игрока
  - **Chaser**: преследует игрока используя поиск пути (BFS)
- Столкновение с врагом или пулей → Game Over.
- Собрав все точки → победа.

---

## Таблица рекордов

- Хранится в `config/records.json`.
- Менеджер `RecordManager` хранит топ-5 лучших результатов.
- После окончания игры, если набран новый рекорд, предлагается ввести имя.
- Экран Records отображает список лучших игроков.

---

## Экран справки

- Отображается через кнопку **Help** в меню.
- Содержит правила игры и управление.
- ESC возвращает в главное меню.

---

## Звуки и музыка

- Музыка меню и игры загружается отдельно (`menu.mp3`, `game.mp3`).
- Звуки бонуса и столкновений подключаются через `pygame.mixer.Sound`.

---

## Запуск игры

1. Убедитесь, что установлены зависимости:

```bash
pip install pygame
````

2. Запустите:

```bash
python main.py
```

3. В меню выберите **Start Game**, **Records**, **Help** или **Exit**.

---

## Настройки

Все основные константы находятся в `config/config.py`:

* Размер карты, тайлов и спрайтов
* Цвета, пути к ресурсам
* FPS и музыка

## Особенности реализации

* Плавное движение игрока и врагов по центру клеток.
* Простая система бонусов с эффектами.
* Враги реализованы с поведением "случайное движение" и "преследование".
* Таблица рекордов в JSON с топ-5.
* Отдельный класс `Menu` для всех экранов и интерфейса.
