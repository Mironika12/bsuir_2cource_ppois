# Отчёт по лабораторной работе №2

## Разработка GUI-приложения для управления данными студентов

---

## 1. Цель работы

Целью лабораторной работы является изучение принципов разработки графических пользовательских интерфейсов и создание оконного приложения с использованием архитектурного шаблона **MVC (Model-View-Controller)**.

---

## 2. Описание разработанной системы

Разработано десктопное приложение на языке Python с использованием библиотеки **PyQt6**, предназначенное для управления данными студентов и их экзаменов.

Система позволяет:

* добавлять записи о студентах;
* выполнять поиск по различным условиям;
* удалять записи;
* сохранять и загружать данные в формате XML;
* отображать данные в табличном и древовидном виде;
* работать с базой данных SQLite.

---

## 3. Архитектура системы

Приложение построено по шаблону **MVC**.

### 3.1 Model (Модель)

Отвечает за хранение и обработку данных:

* `Student` — модель студента
* `Exam` — модель экзамена
* `Database` — работа с SQLite
* `StudentRepository` — доступ к данным

---

### 3.2 View (Представление)

Отвечает за интерфейс пользователя:

* `MainWindow` — главное окно
* `AddDialog` — добавление студента
* `SearchDialog` — поиск
* `DeleteDialog` — удаление

---

### 3.3 Controller (Контроллер)

Связывает модель и интерфейс:

* `MainController` управляет:

  * добавлением
  * поиском
  * импортом/экспортом XML

---

### 3.4 Сервисный слой

* `SearchService` — логика поиска
* `XMLService` — экспорт (DOM)
* `XMLReader` — импорт (SAX)

---

## 4. Хранение данных

### 4.1 База данных

Используется **SQLite**.

Структура:

* таблица `students`:

  * id
  * fio
  * group_name

* таблица `exams`:

  * id
  * student_id
  * subject
  * score

---

### 4.2 XML

Реализовано:

* запись — через **DOM**
* чтение — через **SAX**

Пример структуры:

```xml
<students>
  <student fio="Иванов И.И." group="421701">
    <exams>
      <exam subject="Математический анализ" score="8"/>
    </exams>
  </student>
</students>
```

---

## 5. Функциональные возможности

### 5.1 Добавление студента

* ввод ФИО и группы
* добавление экзаменов
* валидация данных через regex
* сохранение в БД

---

### 5.2 Поиск

Поддерживаются условия:

* по группе
* по предмету и диапазону баллов
* по среднему баллу

Результаты отображаются с пагинацией.

---

### 5.3 Удаление

Удаление выполняется:

* по группе
* по предмету и баллам
* по среднему баллу

Выводится количество удалённых записей.

---

### 5.4 Отображение данных

Реализовано два режима:

* табличный вид
* древовидный вид (студент → экзамены)

---

### 5.5 Пагинация

Поддерживается:

* переход между страницами
* выбор количества записей
* отображение текущей страницы
* отображение общего числа записей

---

### 5.6 XML

* экспорт данных в файл
* импорт данных с заменой текущих

Обработка некорректного XML:

* игнорируются некорректные элементы
* предотвращены ошибки парсинга

---

## 6. Валидация данных

Используются регулярные выражения :

* ФИО: `Иванов И.И.`
* группа: 6 цифр
* предмет: только буквы

Проверяется:

* формат данных
* диапазон баллов (0–10)

## 7. Сценарии демонстрации системы

---

### Сценарий 1 — Добавление данных

1. Открыть приложение
2. Нажать "Добавить"
3. Ввести:

   * ФИО
   * группу
   * экзамены
4. Нажать "Сохранить"

Результат: студент появляется в таблице

---

### Сценарий 2 — Поиск

1. Нажать "Поиск"
2. Ввести условия (например):

   * группа
   * диапазон баллов
3. Нажать "Найти"

Результат:

* отображаются найденные записи
* работает пагинация

---

### Сценарий 3 — Удаление

1. Нажать "Удалить"
2. Ввести условия
3. Подтвердить

Результат:

* выводится количество удалённых записей

---

### Сценарий 4 — Переключение отображения

1. Переключиться на вкладку "Дерево"

Результат:

* данные отображаются в виде иерархии

---

### Сценарий 5 — Экспорт XML

1. Выбрать "Экспорт XML"
2. Указать файл

Результат:

* создаётся XML-файл

---

### Сценарий 6 — Импорт XML

1. Выбрать "Импорт XML"
2. Подтвердить замену данных
3. Выбрать файл

Результат:

* данные загружаются из XML

---

### Сценарий 7 — Некорректный XML

1. Загрузить повреждённый XML

Результат:

* программа не падает
* некорректные данные игнорируются
